Component - Each element in the web page is a component

JSX - JavaScript XML

Vite is a package which helps to work faster by refreshing the webpage as soon as the file is saved.

All JSX files in React should be in the Pascal Case:
Home.jsx
AboutUs.jsx
ServiceCard.jsx

URL: http://localhost:5173

HTTP: Hyper Text Transfer Protocol (For Request & Response)
localhost: Currently working in our local system without any custom domain
5173: Default Port Number for Vite. If used by other service (Port will change automatically)

React Default Port Number: 3000
